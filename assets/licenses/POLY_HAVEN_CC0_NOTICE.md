# Poly Haven production assets

The downloaded Poly Haven meshes and texture maps in this directory are
provided under the creator's CC0 asset declaration:

- Primary declaration: https://polyhaven.com/license
- Legal instrument: https://creativecommons.org/publicdomain/zero/1.0/
- Local legal text: `assets/licenses/CC0-1.0.txt`
- Retrieved and checked: 2026-10-23

The primary page expressly permits redistribution of downloaded CC0 assets.
This notice concerns the downloadable assets. It does not assert that Poly Haven
website logos, preview renders or all website text are CC0. No website preview
renders or logos are bundled.

The material contact sheet was made from the actual bundled CC0 diffuse maps.
Original author names, source pages, download URLs and checksums are retained
in `assets/ASSET_CATALOG.json`, `assets/source_metadata/` and
`research/asset_sources.json`.

Metadata was obtained using the public Poly Haven API with the distinct
`PALAGAN-Surabaya-Reconstruction-Kit/1.0 (asset research)` User-Agent and an
identifying Referer. API terms were inspected at:
https://github.com/Poly-Haven/Public-API/blob/master/ToS.md

The kit does not require live API calls to use its bundled assets. No paid
download, subscription or API key is needed for the included files.

These are contemporary production resources. CC0 permission does not establish
that an object, material, colour or construction detail existed in Surabaya in
1945. The historical reference briefs govern that judgement.
