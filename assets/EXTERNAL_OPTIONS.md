# Optional external sources, not dependencies

These sources were considered but their files are not included in this kit.
The included library already has the bytes needed for its selected assets.

| Source | Primary entry point | Role | Status |
|---|---|---|---|
| ambientCG | https://ambientcg.com/ | Additional neutral surfaces | Plaster001 and Bricks052 creator pages inspected; they identify CC0. No files downloaded or relied upon. Check the exact asset and its metadata before adding it. |
| Poly Haven public API source | https://github.com/Poly-Haven/Public-API | Metadata/tooling reference | API terms inspected; no server code is needed to use the local assets. |
| Kenney catalogue | https://kenney.nl/assets | Other inexpensive background props | Only the selected Survival Kit timber models are bundled. Check each other pack's licence and visual/historical fit. |

Do not assume that every free download from another site can be redistributed.
Do not add modern props, European architectural kits, fantasy assets or generic
characters merely because they are convenient. Any new asset requires a source,
licence record, local dependency check and an explicit historical-fit decision.
