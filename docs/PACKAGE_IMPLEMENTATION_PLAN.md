# PALAGAN preparation package implementation plan

Goal: deliver a self-contained research and execution kit for OpenCode and Blender 5.2.

Architecture: source documents and permitted images feed an evidence register and landmark briefs. A map-derived local layout, persistent progress protocol and incremental Blender helpers feed the downstream construction agent.

Specification: `docs/APPROVED_SPEC.md`.

## Task 1: Acquire the source base
- [x] Acquire and inspect a high-resolution period-map image and its provenance.
- [x] Inspect period landmark images, institutional records and historical accounts.
- [x] Preserve source IDs, exact access state, date distinctions and reuse information.
- [x] Verify every included local asset exists and matches its recorded checksum.

## Task 2: Prepare spatial and architectural instructions
- [x] Select an evidence-supported map crop and document image orientation and scale.
- [x] Trace key routes, water and a limited set of footprints with source-pixel provenance.
- [x] Record approximation and any unperformed georeferencing honestly.
- [x] Link all features and landmarks to source IDs and briefs.

## Task 3: Build the recoverable agent workflow
- [x] Implement and test atomic operation state, checkpoint copying, hashes and reconcile.
- [x] Provide scene preflight, owned-object patterns and inspection helpers.
- [x] Add optional version-sensitive compaction integration and fallback instructions.
- [x] Ensure all downstream commands reference the actual included interfaces.

## Task 4: Integrate the handoff
- [x] Write the starting prompt, project instructions, build phases and visual review criteria.
- [x] Consolidate research, source and asset indexes without inventing access statuses.
- [x] Validate JSON/CSV, relative links, included assets, scripts and archive integrity.
- [x] Review package as a fresh downstream agent and repair gaps.
- [x] Save the final ZIP and deliver its download link.

Review focus: unavailable historical scans; incorrect image dates; source-pixel coordinate mistakes; duplicate geometry after compaction; checkpoints marked complete before a verified scene save; dependencies assumed installed; generation-time claims confused with local Blender tests.
